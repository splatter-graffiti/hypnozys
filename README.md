## Standard art exhibition

For an **art exhibition**, there are some common standard sizes, but there isn't one universal size. The best choice depends on whether you mean a **poster advertising the exhibition** or an **artwork/picture being exhibited**.

### Standard art exhibition poster size

The most standard sizes are:

| Size                    | Orientation | Common use                          |
| ----------------------- | ----------- | ----------------------------------- |
| **A2 — 42 × 59.4 cm**   | Portrait    | ⭐ Very common exhibition poster    |
| **A3 — 29.7 × 42 cm**   | Portrait    | Smaller posters / gallery notices   |
| **A1 — 59.4 × 84.1 cm** | Portrait    | Large promotional poster            |
| **50 × 70 cm**          | Portrait    | Very common non-A paper poster size |

**If you're designing an exhibition poster yourself, I'd recommend A2 (42 × 59.4 cm)** unless the gallery gives you specific dimensions.

For a poster on a wall, **A2 portrait** is a particularly practical standard: large enough to be visible, but not excessively large.

---

### Standard size of an art picture for an exhibition

There isn't really one "standard" artwork size. Galleries commonly display a range of sizes.

Some very common framed/printed artwork dimensions are:

| Artwork size     | Typical use                   |
| ---------------- | ----------------------------- |
| **30 × 40 cm**   | Small artwork                 |
| **40 × 50 cm**   | Small/medium                  |
| **50 × 70 cm**   | ⭐ Very common medium artwork |
| **60 × 80 cm**   | Medium/large                  |
| **70 × 100 cm**  | Large statement artwork       |
| **80 × 120 cm**  | Large artwork                 |
| **100 × 150 cm** | Very large / centerpiece      |

If you're looking for **one safe, conventional size for an art print/picture**, **50 × 70 cm** is a very common choice.

### One important distinction

If you're preparing files in **Photoshop for printing**, I'd think of it like this:

- **Exhibition poster:** **A2 = 42 × 59.4 cm**
- **Artwork/print:** **50 × 70 cm**
- **Large artwork:** **70 × 100 cm**
- **Small artwork:** **30 × 40 cm**

And if your artwork is going onto a **transparent computer case/panel**, as you mentioned previously, that's a different situation—the physical dimensions of the case/panel should determine the Photoshop document size rather than using an exhibition standard.
